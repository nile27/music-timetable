# 4. 화면설계서

<aside>
🎨

이 문서는 화면별 **구성 요소와 동작**만 정의합니다. 색·폰트·배치 등 시각 디자인은 Stitch 등 디자인 툴로 시안을 만들어 보고 결정합니다. 아래 와이어프레임은 구성 확인용 스케치입니다.

Figma 화면설계: [Figma에서 보기](https://www.figma.com/design/Q7Qb5n7gAdBDj6oCWrW2o1?node-id=5-2)

## 0. 공통

- 화면 구성: 탭 4개 — 재생 / 시간표 / 노래 / 설정
- 디자인 방향: 현재 곡 커버를 화면 전체 배경에 크게 블러 처리 + 반투명 어두운 레이어, 그 위에 선명한 커버와 정보 (음악 스트리밍 앱 재생 화면과 유사한 느낌). 곡이 바뀔 때 배경은 opacity 전환
- 창 상단: Windows 기본 최소화/최대화/닫기 버튼만 남기고 배경은 끝까지 채움. macOS에서 개발 중에는 상단 버튼 모양이 다르게 보임
- 모든 문구는 쉬운 한국어, 버튼은 크고 명확하게
- (6단계 확정) 디자인 값은 Figma 디자인 시스템(11:2)과 전달 파일(`local전용/figma/`, git 제외)을 따른다. 앱 이름 표시는 "음악 시간표"(Figma의 "음악 자동 재생" 대신). 글꼴 IBM Plex Sans KR은 앱에 내장(400/600/700, OFL)
- (6단계 확정) 왼쪽 탭 메뉴 아래 "지금 상태" 카드에 항상 상태와 다음 재생을 표시 (NFR-05, 어느 탭에서든 보임). 재생 화면은 배경 어두운 막 0.60, 다른 화면은 0.72
- (6단계 확정) 창 위쪽 32px은 끌어서 창 이동, 오른쪽 140×32는 Windows 창 버튼 자리

## S-01. 재생 화면 (메인)

```
+------------------------------------------------+
| [재생] [시간표] [노래] [설정]        _ □ X  |
|                                                |
|   +-----------+    곡 제목                      |
|   |           |    가수 이름                    |
|   |   커버    |                                |
|   |           |    ● 재생 중: 점심               |
|   +-----------+      13:00 ~ 14:00 (32분 남음)   |
|                                                |
|         [ ▶ / ■ ]          볼륨 ---o----      |
|  ------------------o------------  1:23 / 3:45  |
|                                                |
|  [ 오늘은 재생 안 함 ]                         |
+------------------------------------------------+
```

| 요소 | 동작 |
| --- | --- |
| 상태 표시 | 상태 알약 + 큰 제목 + 오른쪽 남은 시간. 재생 중(노랑) “점심 · 13:00~14:00 / 32분 남음”, 대기 중(파랑) “다음 재생: 오후 1:00 점심 / 1시간 12분 뒤”, 직접 재생(노랑) “정지할 때까지 재생해요”, 오늘은 재생 안 함(회색) “오늘은 음악이 나오지 않아요”, 다른 쉬는 날(회색) “오늘은 쉬는 날이에요 (사유)”. 항상 크게 표시 (NFR-05) |
| 커버·제목·가수 | 대기 중에는 다음에 나올 곡을 표시 |
| 재생/정지 버튼 | 수동 재생·정지 (FR-08) |
| 진행 막대 | 현재 곡 진행률과 시간 표시만 한다. 눌러서 위치를 옮기는 기능은 없음 (6단계 결정: 시간표대로 트는 앱이라 실수로 위치가 바뀌지 않게). 대기 중에는 다음 곡 길이를 보여줌 |
| 볼륨 | 변경 즉시 저장 |
| 오늘은 재생 안 함 | 토글. 켜면 재생 중인 음악도 멈춤. 다음 날 자동 해제 (FR-13). 켜진 동안 버튼 문구는 “오늘 다시 재생하기”. 켜져 있어도 [재생] 버튼으로 직접 재생은 가능 |

## S-02. 시간표 화면

```
+------------------------------------------------+
|  재생 시간 (매일 동일, 주말 제외)                  |
|  이름        시작      종료                     |
|  [등교    ] [08:30]  [09:00]   [삭제]          |
|  [점심    ] [13:00]  [14:00]   [삭제]          |
|  [하교    ] [17:50]  [18:30]   [삭제]          |
|  [ + 시간 추가 ]                    [저장]     |
|                                                |
|  쉬는 날               < 2026년 10월 >          |
|  일 월 화 수 목 금 토                          |
|  (주말=회색, 공휴일=표시, 클릭하면 쉬는 날 지정)  |
+------------------------------------------------+
```

| 요소 | 동작 |
| --- | --- |
| 시간 목록 | 이름·시작·종료 입력, 시작 시각 순으로 자동 정렬 (FR-01) |
| 저장 | 시작 ≥ 종료, 구간 겹침이 있으면 해당 줄 표시 + 안내 문구, 저장 막음 (FR-07) |
| 쉬는 날 달력 | 주말은 회색(변경 불가), 내장 공휴일은 이름과 함께 표시, 평일을 클릭하면 쉬는 날 추가/해제 (FR-11, FR-12). 내장 공휴일을 재생하는 날로 바꾸는 기능은 MVP에서 만들지 않는다 (필요하면 [재생] 버튼으로 직접 재생) |

## S-03. 노래 화면

```
+------------------------------------------------+
|  +------------------------------------------+  |
|  |   여기에 음악 파일을 끌어다 놓으세요          |  |
|  +------------------------------------------+  |
|  총 24곡                       [폴더 열기]    |
|  1. [커버] 곡 제목 - 가수                      |
|  2. [커버] 곡 제목 - 가수   ← 다음 곡          |
|  ...                                           |
+------------------------------------------------+
```

| 요소 | 동작 |
| --- | --- |
| 드롭 영역 | 파일을 끌고 오면 강조 표시. 놓으면 음악 폴더로 복사 후 “N곡을 추가했어요”. 음악이 아닌 파일은 “음악 파일이 아니라서 제외했어요” (FR-21, FR-23). 같은 이름 파일이 이미 있으면 덮어쓰지 않고 건너뛴 뒤 “이미 있는 노래라서 제외했어요” |
| 곡 목록 | 재생 순서(파일 이름 자연 정렬: 한글 가나다, 숫자 크기순)대로 표시, 다음 재생 곡 표시. 폴더 변경 시 자동 갱신 (FR-22). **MVP에서는 삭제·순서 변경 UI를 만들지 않는다.** 순서는 파일 이름으로 정하고(앞에 01_, 02_ 등 번호를 붙여 조정), 삭제는 [폴더 열기] 후 탐색기에서 한다 |
| 폴더 열기 | 음악 폴더(내 음악/음악 시간표)를 Windows 탐색기로 열기. 곡 삭제·이름 변경은 여기서 |
| 빈 상태 | 곡이 0개면 “아직 노래가 없어요. 위에 파일을 끌어다 놓아주세요” |

## S-04. 설정 화면

| 항목 | 동작 |
| --- | --- |
| PC 켜질 때 자동 실행 | 토글, 기본 켜짐 (FR-31) |
| 앱 정보 | 버전, 공휴일 데이터 수록 연도 (예: “공휴일 정보: 2027년까지”) |
| 창 안내 | 설정 탭 맨 아래 작은 안내 문구만 둘: “창만 숨기려면 – 버튼을 눌러주세요. X를 누르면 프로그램이 꺼져서 정해진 시간에 음악이 나오지 않아요.” 별도 종료 버튼은 두지 않음 (FR-34). Figma 설정 화면의 “설정 파일”·“프로그램 종료” 영역과 종료 확인 창(10:2)은 쓰지 않음 |

## S-05. 창 동작 (트레이 없음)

- 최소화(–): 창을 작업 표시줄로 숨김. 재생·스케줄은 그대로 동작
- 닫기(X): 확인 없이 바로 종료 (재생 위치는 저장)
- 작업 표시줄 아이콘 클릭: 창 다시 열기
- 설명서에 “숨길 때는 –, X는 종료”를 그림으로 안내

## 안내 문구 모음 (초안)

| 상황 | 문구 |
| --- | --- |
| 곡 파일을 찾을 수 없을 때 | 노래 파일을 찾을 수 없어서 다음 곡을 틀었어요. |
| 재생 시간인데 곡이 없을 때 | 재생할 노래가 없어요. 노래 탭에서 추가해주세요. |
| 시간표 오류 | 끝나는 시간이 시작 시간보다 빨라요. / 다른 시간과 겹쳐요. |
