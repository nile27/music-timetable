# 4. 화면설계서

<aside>

## 0. 공통

- 화면 구성: 탭 4개 — 재생 / 시간표 / 노래 / 설정
- 디자인 방향: 현재 곡 커버를 화면 전체 배경에 크게 블러 처리 + 반투명 어두운 레이어, 그 위에 선명한 커버와 정보 (음악 스트리밍 앱 재생 화면과 유사한 느낌). 곡이 바뀔 때 배경은 opacity 전환
- 창 상단: Windows 기본 최소화/최대화/닫기 버튼만 남기고 배경은 끝까지 채움. macOS에서 개발 중에는 상단 버튼 모양이 다르게 보임
- 모든 문구는 쉬운 한국어, 버튼은 크고 명확하게

## S-01. 재생 화면 (메인)

```
+------------------------------------------------+
| [재생] [시간표] [노래] [설정]        _ □ X  |
|                                                |
|   +-----------+    곡 제목                      |
|   |           |    가수 이름                    |
|   |   커버    |                                |
|   |           |    ● 재생 중: 점심               |
|   +-----------+      13:00 ~ 14:00 (32분 남음)   |
|                                                |
|         [ ▶ / ■ ]          볼륨 ---o----      |
|  ------------------o------------  1:23 / 3:45  |
|                                                |
|  [ 오늘은 재생 안 함 ]                         |
+------------------------------------------------+
```

| 요소 | 동작 |
| --- | --- |
| 상태 표시 | 재생 중이면 “재생 중: 구간명 / 남은 시간”, 대기 중이면 “다음 재생: 오후 1:00 점심”, 쉬는 날이면 “오늘은 쉬는 날이에요 (사유)”. 항상 크게 표시 (NFR-05) |
| 커버·제목·가수 | 대기 중에는 다음에 나올 곡을 표시 |
| 재생/정지 버튼 | 수동 재생·정지 (FR-08) |
| 진행 막대 | 현재 곡 진행률 표시 (클릭 이동 여부는 디자인 단계에서 결정) |
| 볼륨 | 변경 즉시 저장 |
| 오늘은 재생 안 함 | 토글. 켜면 재생 중인 음악도 멈춤. 다음 날 자동 해제 (FR-13) |

## S-02. 시간표 화면

```
+------------------------------------------------+
|  재생 시간 (매일 동일, 주말 제외)                  |
|  이름        시작      종료                     |
|  [등교    ] [08:30]  [09:00]   [삭제]          |
|  [점심    ] [13:00]  [14:00]   [삭제]          |
|  [하교    ] [17:50]  [18:30]   [삭제]          |
|  [ + 시간 추가 ]                    [저장]     |
|                                                |
|  쉬는 날               < 2026년 10월 >          |
|  일 월 화 수 목 금 토                          |
|  (주말=회색, 공휴일=표시, 클릭하면 쉬는 날 지정)  |
+------------------------------------------------+
```

| 요소 | 동작 |
| --- | --- |
| 시간 목록 | 이름·시작·종료 입력, 시작 시각 순으로 자동 정렬 (FR-01) |
| 저장 | 시작 ≥ 종료, 구간 겹침이 있으면 해당 줄 표시 + 안내 문구, 저장 막음 (FR-07) |
| 쉬는 날 달력 | 주말은 회색(변경 불가), 내장 공휴일은 이름과 함께 표시, 평일을 클릭하면 쉬는 날 추가/해제 (FR-11, FR-12). 내장 공휴일을 재생하는 날로 바꾸는 기능 필요 여부는 미정 |

## S-03. 노래 화면

```
+------------------------------------------------+
|  +------------------------------------------+  |
|  |   여기에 음악 파일을 끌어다 놓으세요          |  |
|  +------------------------------------------+  |
|  총 24곡                       [폴더 열기]    |
|  1. [커버] 곡 제목 - 가수                      |
|  2. [커버] 곡 제목 - 가수   ← 다음 곡          |
|  ...                                           |
+------------------------------------------------+
```

| 요소 | 동작 |
| --- | --- |
| 드롭 영역 | 파일을 끌고 오면 강조 표시. 놓으면 음악 폴더로 복사 후 “N곡을 추가했어요”. 음악이 아닌 파일은 “음악 파일이 아니라서 제외했어요” (FR-21, FR-23). 같은 이름 파일 처리 방식은 미정 |
| 곡 목록 | 재생 순서대로 표시, 다음 재생 곡 표시. 폴더 변경 시 자동 갱신 (FR-22). 삭제·순서 변경 UI는 정렬 기준 확정 후 결정 |
| 폴더 열기 | 음악 폴더를 Windows 탐색기로 열기 |
| 빈 상태 | 곡이 0개면 “아직 노래가 없어요. 위에 파일을 끌어다 놓아주세요” |

## S-04. 설정 화면

| 항목 | 동작 |
| --- | --- |
| PC 켜질 때 자동 실행 | 토글, 기본 켜짐 (FR-31) |
| 설정 내보내기 | 시간표·쉬는 날·볼륨을 파일로 저장 (FR-32) |
| 설정 가져오기 | 파일 선택 → “현재 설정을 바꿀까요?” 확인 후 적용 |
| 앱 정보 | 버전, 공휴일 데이터 수록 연도 (예: “공휴일 정보: 2027년까지”) |
| 창 안내 | 설정 탭 맨 아래 작은 안내 문구만 둘: “창만 숨기려면 – 버튼을 눌러주세요. X를 누르면 프로그램이 꺼져서 정해진 시간에 음악이 나오지 않아요.” 별도 종료 버튼은 두지 않음 (FR-34) |

## S-05. 창 동작 (트레이 없음)

- 최소화(–): 창을 작업 표시줄로 숨김. 재생·스케줄은 그대로 동작
- 닫기(X): 확인 없이 바로 종료 (재생 위치는 저장)
- 작업 표시줄 아이콘 클릭: 창 다시 열기
- 설명서에 “숨길 때는 –, X는 종료”를 그림으로 안내

## 안내 문구 모음 (초안)

| 상황 | 문구 |
| --- | --- |
| 곡 파일을 찾을 수 없을 때 | 노래 파일을 찾을 수 없어서 다음 곡을 틀었어요. |
| 재생 시간인데 곡이 없을 때 | 재생할 노래가 없어요. 노래 탭에서 추가해주세요. |
| 시간표 오류 | 끝나는 시간이 시작 시간보다 빨라요. / 다른 시간과 겹쳐요. |
