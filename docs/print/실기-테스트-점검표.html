실제 PC 테스트 점검표 (7단계)

docs/milestones.md 7단계 완료 기준(= PRD 성공 기준)을 실제 Windows PC에서 확인합니다. 설치는 docs/설치-체크리스트.md를 먼저 따르세요. 문제가 있으면 번호 + 로그 파일(%APPDATA%\music-timetable\logs\main.log)을 전달해 주세요.

A. 설치·첫 실행

#확인할 것결과
A1설치 파일 실행만으로 설치가 끝나고 프로그램이 켜진다 (NFR-06)
A2바탕화면·시작 메뉴 아이콘 이름이 "음악 시간표"이고 아이콘이 노란 음표다 (FR-35)
A3창 오른쪽 위에 최소화(–)·최대화·닫기(X) 버튼이 보이고, 배경색과 어울린다
A4창 위쪽 빈 곳을 끌면 창이 움직인다
A5글자가 IBM Plex 글꼴로 보이고 깨지지 않는다
A6로그 첫 줄 근처 "[app] 음악 폴더: …" 경로 기록 (OneDrive 여부: 아님 OneDrive)

B. 자동 재생 (테스트용 짧은 시간으로)

시간표에 "지금 + 2분 ~ 지금 + 4분" 구간을 하나 추가해 저장한 뒤 확인합니다. 끝나면 원래대로 돌려 놓으세요.

#확인할 것결과
B1최소화(–)한 상태로 시작 시각에 음악이 저절로 나온다 (FR-02, FR-30)
B2종료 시각에 곡 중간이라도 바로 멈춘다 (FR-03)
B3구간을 하나 더 만들면 아까 끊긴 곡의 다음 곡부터 나온다 (FR-04)
B4구간 도중에 X로 끄고 다시 켜면, 남은 시간 동안 다음 곡부터 바로 나온다 (FR-05, FR-06, FR-34)
B5재생 중 흐린 배경 때문에 소리가 끊기거나 PC가 느려지지 않는다 (NFR-07)

C. 쉬는 날

#확인할 것결과
C1달력에서 오늘을 쉬는 날로 누르면 재생 중이던 음악이 멈추고 "오늘은 쉬는 날이에요"가 나온다 (FR-12)
C2"오늘은 재생 안 함"을 켜면 멈추고, 다음 날 아침에는 저절로 다시 나온다 (FR-13)
C3주말(토·일)에는 나오지 않는다 (FR-10) — 1주일 운영 중 확인

D. 무인 운영

#확인할 것결과
D1PC를 다시 켜고 로그인하면 프로그램이 저절로 켜지고 작업 표시줄에 최소화로 있다 (FR-31)
D2이미 켜져 있을 때 바탕화면 아이콘을 또 누르면 새로 켜지지 않고 기존 창이 앞으로 온다
D3다음 날 로그에 "[system] 새벽 재시작"(03:00~04:00)이 있고, 그 뒤에도 정상 동작한다 (NFR-03)
