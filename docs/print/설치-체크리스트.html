음악 시간표 설치 체크리스트

새 PC에 설치할 때 위에서부터 차례대로 확인하세요. (설치 파일: music-timetable-1.0.0-setup.exe)

1. 설치 전 PC 설정

  • 절전(잠자기) 끄기: 설정 → 시스템 → 전원 → "절전 모드로 전환"을 안 함으로. (잠자기 상태에서는 음악이 나오지 않아요. 화면 꺼짐·잠금은 괜찮아요.)
  • Windows 로그인 비밀번호 확인: 비밀번호가 있으면 업데이트로 다시 켜진 뒤 로그인할 때까지 음악이 나오지 않아요. 가능하면 자동 로그인을 켜 두세요.
  • 스피커·볼륨: 스피커가 연결돼 있고, 볼륨이 켜져 있으며 음소거가 아닌지 확인하세요.
  • 날짜·시간: 작업 표시줄 오른쪽 시계가 정확한지 확인하세요 (설정 → 시간 및 언어 → 자동으로 시간 설정).

2. 설치

  • 설치 파일을 더블클릭하세요.
  • "Windows의 PC 보호" 파란 창이 뜨면: 추가 정보 → 실행을 누르세요. (서명하지 않은 프로그램이라 처음 한 번 뜨는 경고예요.)
  • 따로 묻는 것 없이 설치가 끝나고 프로그램이 저절로 켜져요.
  • 바탕화면과 시작 메뉴에 "음악 시간표" 아이콘이 생겼는지 확인하세요.

3. 설치 직후 확인

  • 재생 탭 위쪽에 "다음 재생: …"이 보이는지 (시간표가 기본값으로 들어 있어요: 등교 08:30~09:00 / 점심 13:00~14:00 / 하교 17:50~18:30)
  • 노래 탭에 음악 파일을 넣고, [폴더 열기]로 음악 폴더 위치를 확인하세요.
  • 보통: C:\Users\(사용자 이름)\Music\음악 시간표
  • OneDrive 안(…\OneDrive\음악\음악 시간표 등)으로 열리면 OneDrive가 "음악" 폴더를 옮겨 둔 PC예요. 동작은 하지만, OneDrive 동기화가 꺼지거나 용량이 차면 문제가 될 수 있으니 기록해 두세요.
  • 설정 탭에서 "PC 켜질 때 자동 실행"이 켜짐인지 확인하세요.
  • 재생 탭에서 [지금 재생]을 눌러 소리가 나는지, [정지]로 멈추는지 확인하세요.

4. 문제가 생겼을 때 볼 곳

무엇위치 (파일 탐색기 주소창에 붙여 넣기)
음악 폴더노래 탭 → [폴더 열기]
기록(로그) 파일%APPDATA%\music-timetable\logs\main.log
설정 파일%APPDATA%\music-timetable\settings.json
설치 위치%LOCALAPPDATA%\Programs\music-timetable

로그 파일에는 켜지고 꺼진 시각, 음악을 틀고 멈춘 시각과 이유, 쉬는 날이라 건너뛴 이유, 오류가 남아요. 문의할 때 이 파일을 함께 보내 주세요.

5. PC를 옮길 때

  • 기존 PC의 음악 폴더(Music\음악 시간표)를 USB로 복사하세요.
  • 새 PC에 설치한 뒤 음악 폴더에 복사해 넣으세요 (노래 탭 → [폴더 열기]).
  • 시간표가 기본값과 다르면 다시 입력하고, 앞으로 남은 쉬는 날을 달력에서 다시 눌러 주세요. (설정 옮기기 기능은 없어요.)
  • 위 1~3번을 다시 확인하세요.
