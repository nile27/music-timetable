# 2. PRD (제품 요구사항 문서)

## 1. 배경

교육장에서 등교·점심시간·하교 시간에 음악을 틀고자 한다. 등교 시간(8:30~9:00)은 담당 연구원님 출근(9:00) 전이라 사람이 직접 틀 수 없다. Windows 작업 스케줄러 등으로도 구현은 가능하지만, 시간 변경·곡 추가가 비개발자에게 어렵고 정지 처리가 불편하다.

### 확정 시간표 (매일 동일, 평일만)

| 구간 | 시작 | 종료 | 길이 |
| --- | --- | --- | --- |
| 등교 | 08:30 | 09:00 | 30분 |
| 점심 | 13:00 | 14:00 | 60분 |
| 하교 | 17:50 | 18:30 | 40분 |

하루 총 재생 시간은 130분이다. 이 시간표를 앱 기본값으로 넣는다 (FR-33).

## 2. 목표

- 비개발자인 연구원님이 혼자서 시간표와 노래를 관리할 수 있다.
- 사람이 없어도 정해진 시간에 자동으로 재생·정지된다.
- 주말·공휴일에는 재생되지 않는다.
- PC가 바뀌어도 쉽게 옮겨 설치할 수 있다.

## 3. 비목표 (이번 버전에서 하지 않음)

- 인터넷 스트리밍, 온라인 공휴일 조회
- 여러 PC 동시 재생 및 동기화
- 요일별 다른 시간표, 랜덤 재생, 페이드아웃
- 로그인·계정 기능
- macOS용 배포 (개발은 macOS, 배포는 Windows만)

## 4. 핵심 사용 시나리오

### 시나리오 A. 평일 아침 (무인)

1. PC는 밤새 켜져 있고 앱은 최소화된 상태로 실행 중이다.
2. 8:30이 되면 앱이 오늘이 평일이고 쉬는 날이 아닌지 확인한다.
3. 지난번 끊긴 곡의 다음 곡부터 재생한다.
4. 9:00에 곡 중간이라도 바로 멈추고 재생 위치를 저장한다.

### 시나리오 B. 노래 추가

1. 연구원님이 작업 표시줄에서 앱을 눌러 창을 연다.
2. 노래 탭에 mp3 파일을 드래그앤드롭한다.
3. 파일이 음악 폴더로 복사되고 목록에 바로 표시된다.

### 시나리오 C. 갑자기 쉬는 날

1. 임시공휴일이 발표되면 시간표 탭 달력에서 해당 날짜를 쉬는 날로 지정한다.
2. 당일 급하게 끌 때는 메인 화면의 “오늘은 재생 안 함”을 누른다.

### 시나리오 D. 재부팅 후 복구

1. Windows 업데이트로 PC가 재부팅된다.
2. 로그인 후 앱이 자동 실행된다.
3. 현재 시각이 구간 도중이면 남은 시간만큼 즉시 재생한다.

### 시나리오 E. PC 이전

1. 기존 PC의 음악 폴더(내 음악/음악 시간표)를 USB로 복사한다.
2. 새 PC에 설치 후 음악 폴더를 복사하고, 시간표(기본값과 다르면)·쉬는 날·볼륨을 다시 입력한다. (설정 내보내기/가져오기는 2026-10-14 삭제: FR-32)
3. 설치 체크리스트(절전 해제 등)를 따라 확인한다.

### 시나리오 F. 프로그램 종료·다시 켜기

1. 창만 숨기려면 최소화(–)를 누른다. 재생·스케줄은 계속 동작한다.
2. 닫기(X)를 누르면 재생 위치를 저장하고 바로 종료된다.
3. 다시 켤 때는 시작 메뉴나 바탕화면 아이콘을 누른다. 다시 켜지 않아도 자동 실행이 켜져 있으면 PC를 다시 켤 때 실행된다.

## 5. 기능 범위 (1차 버전)

상세 항목은 “1. 사용자 요구정의서”의 FR/NFR 번호를 따른다.

- 시간표 및 자동 재생·정지, 이어서 재생, 늦게 켜져도 따라잡기 (FR-01~08)
- 주말·공휴일·쉬는 날 처리 (FR-10~13)
- 음악 폴더 + 드래그앤드롭, 커버 표시 (FR-20~24)
- 최소화 상태 운영(트레이 없음), 자동 실행, 프로그램 종료 (FR-30~35, FR-32 삭제)
- 사용 설명서 1장, 설치 체크리스트

## 6. 성공 기준

- 연구원님이 도움 없이 시간 변경, 노래 추가, 쉬는 날 지정을 할 수 있다.
- 실제 PC에서 1주일 연속 운영 시 모든 구간이 정시에 재생·정지된다.
- 주말과 지정한 쉬는 날에는 재생되지 않는다.
- 재부팅 후 로그인되면 사람 조작 없이 정상 동작으로 복귀한다.

## 7. 개발 단계 (마일스톤)

| 단계 | 내용 | 완료 기준 |
| --- | --- | --- |
| 1 | 프로젝트 생성, 창 띄우기, 곡 하나 재생 | 맥에서 버튼으로 재생/정지 |
| 2 | 음악 폴더 읽기, 폴더 감시, 드래그앤드롭 | 파일 추가/삭제가 목록에 반영 |
| 3 | 시간표 저장, 스케줄러, 이어서 재생, 따라잡기 | 짧은 테스트 구간으로 자동 재생·정지 확인 |
| 4 | 주말·공휴일·쉬는 날, 오늘은 재생 안 함 | 날짜를 바꿔가며 테스트 |
| 5 | 자동 실행, 중복 실행 방지, 새벽 재시작, 로그 | 최소화 상태에서도 재생 유지 |
| 6 | 디자인 적용 (디자인 툴 시안 확정 후) | 화면설계서와 일치 |
| 7 | Windows 빌드, 실제 PC 설치·재부팅 테스트, 설명서 | 실제 PC에서 1주일 운영 |
