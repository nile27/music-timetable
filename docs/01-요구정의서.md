## 4. 운영 제약 및 알려진 한계

- Windows는 절전(잠자기) 상태에서 앱이 멈추므로 PC 전원 설정에서 절전 모드를 꺼야 한다. 화면 꺼짐·잠금은 무관하다.
- 자동 실행은 Windows 로그인 이후에 동작한다. 비밀번호가 있는 PC는 업데이트 재부팅 후 로그인 전까지 재생되지 않는다.
- 대규모 Windows 업데이트 후 “장치 설정 마무리” 안내 화면이 뜨면 바탕화면 진입이 막힐 수 있다.
- 임시공휴일·선거일은 미리 알 수 없으므로 내장 목록으로 처리되지 않는다 (FR-12, FR-13으로 대응).
- 코드 서명 없이 배포하면 최초 실행 시 Windows SmartScreen 경고가 뜬다.
- PC 볼륨이 음소거 상태이면 앱이 정상이어도 소리가 나지 않는다.
- 창이 작업 표시줄에 항상 떠 있고 X를 누르면 바로 종료되므로, 다른 사람이 닫으면 직접 다시 켜거나 PC를 다시 켜기 전까지 재생되지 않는다. 설명서에 “숨길 때는 –, X는 종료”를 안내해 대응한다 (확인 창은 두지 않기로 결정).
