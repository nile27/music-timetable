# 실제 PC 테스트 점검표 (7단계)

`docs/milestones.md` 7단계 완료 기준(= PRD 성공 기준)을 실제 Windows PC에서 확인합니다.
설치는 `docs/설치-체크리스트.md`를 먼저 따르세요. 문제가 있으면 **번호 + 로그 파일**(`%APPDATA%\music-timetable\logs\main.log`)을 전달해 주세요.

| A2 | 바탕화면·시작 메뉴 아이콘 이름이 "음악 시간표"이고 아이콘이 노란 음표다 (FR-35) | ☐ |
| A3 | 창 오른쪽 위에 최소화(–)·최대화·닫기(X) 버튼이 보이고, 배경색과 어울린다 | ☐ |

| B1 | **최소화(–)한 상태로** 시작 시각에 음악이 저절로 나온다 (FR-02, FR-30) | ☐ |
| B2 | 종료 시각에 곡 중간이라도 바로 멈춘다 (FR-03) | ☐ |

| B4 | 구간 도중에 X로 끄고 다시 켜면, 남은 시간 동안 다음 곡부터 바로 나온다 (FR-05, FR-06, FR-34) | ☐ |
