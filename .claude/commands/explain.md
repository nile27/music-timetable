description: 방금 끝난 단계를 개발 초보자도 이해하게 설명한다

---

방금 끝난 단계의 코드를 내가 면접에서 설명할 수 있도록 알려줘. 코드는 고치지 마.

1. 이번 단계에서 만든 기능을 실행 흐름 순서대로 설명해 (어떤 파일의 어떤 함수가 어떤 순서로 불리는지).

2. 중요한 설계 결정 2~3개와 "왜 그렇게 했는지", 다른 방법을 썼으면 어떤 문제가 있었는지.

3. 처음 보는 Electron/TypeScript 개념이 있으면 비유를 들어 짧게 설명해.

4. 면접에서 나올 만한 질문 3개와 모범 답안.

5. 내가 직접 열어서 읽어보면 좋을 파일 2개와 줄 번호.
